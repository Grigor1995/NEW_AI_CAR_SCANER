# ADMIN mode

An explicit local operator may provision ADMIN to an existing account. An account cannot self-grant ADMIN over registration or login APIs. The UI presents the assigned mode; complete management and analytics pages remain PLANNED. Public capabilities and health responses report current implementation status rather than fabricated fleet/user statistics.

Future moderation/update release/configuration operations need granular privileges, MFA, least-privilege data scopes and durable privileged-action audits. ADMIN must not imply private vehicle or ECU-write access. There is no public admin provisioning API in this milestone.
