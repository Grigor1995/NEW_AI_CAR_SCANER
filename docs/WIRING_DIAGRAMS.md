# Wiring diagrams — BLOCKED on licensed data and provider implementation

No manufacturer wiring diagrams, pinouts or circuit layouts are generated or presented as official. Future provider interfaces must return licensed documents with vehicle/engine applicability, source/version, connector context and allowed display/download rights. The viewer will need search, zoom/pan and circuit highlighting; it is not implemented in this milestone.

External licensing, dataset credentials and verified vehicle identification are prerequisites. Do not request secret values in chat or pretend a simulator supplies repair-reference accuracy.
