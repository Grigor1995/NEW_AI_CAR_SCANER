The complete user specification is PRODUCT_REQUIREMENTS.md. This repository is a new C++20/Qt implementation; previous Python/Kotlin/Swift application code is removed from the active tree but remains recoverable in Git history and archive/pre-v3-ac8d946.

Status terms: IMPLEMENTED means source and reported local tests exist; PARTIAL means only the listed slice works; PLANNED means no active implementation; BLOCKED identifies an external prerequisite; UNSUPPORTED means the current implementation deliberately does not support it. No term implies production release readiness.
