# Reference launcher artwork

The user explicitly requested the supplied original launcher design, background,
and 3D icons in the UI correction. These three visual assets were restored from
Grigor1995/AI-CAR-SCANER at a71c547b4b58f88f9c09f7f25d86931b79131bd2,
finalbuild/assets/launcher. The source describes them as project-generated art.
Only artwork is reused; no legacy application/runtime code is restored.

background.png: 1672x941 automotive/circuit background.
icons-3d.png: transparent 1448x1086 atlas, 4 columns x 3 rows (362px cells).
brand-car.png: abstract neon vehicle used for the Vehicles card.
All assets are bundled locally; no network fetch is required.

The standalone installed app icon remains assets/app_icon/canonical.svg.
